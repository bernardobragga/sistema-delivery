# sistema-delivery
MVP de um cardápio digital e sistema de delivery focado em pequenos comércios.

# Sistema de Delivery & Cardápio Digital (MVP)

Cardápio online interativo desenvolvido como MVP para pequenos comércios e comércios locais de bairro, permitindo que clientes façam pedidos de forma prática e recebam os produtos ou enviem os dados diretamente para o WhatsApp do estabelecimento.

## Tecnologias e Ferramentas Utilizadas

O projeto foi construído utilizando tecnologias modernas de Front-end e versionamento:
**HTML5 & CSS3:** Estruturação semântica e estilização visual responsiva.
**JavaScript (Vanilla):** Lógica de manipulação do carrinho, cálculo de totais e integração com APIs externas.
**Git & GitHub:** Controle de versão e colaboração em equipe.

## Funcionalidades da Versão Atual (MVP)
**Cardápio Dinâmico:** Listagem de produtos categorizados (como açaís, sorvetes e milk-shakes).
**Carrinho de Compras:** Adição de itens, controle de quantidade e cálculo automático do valor total.
**Consulta de Endereço via CEP:** Integração com API para preenchimento automático de logradouro e bairro.
**Checkout para WhatsApp:** Formatação automática do pedido e do endereço em uma mensagem pronta para envio.
